# Website photography

Only selected, high-resolution leadership photography belongs in this directory. Public pages load photography directly from `/images`; legacy payload bundles are not an acceptable fallback.

Approved visual roles:

- `jair-conference-stage.webp` — primary leadership image; executive presence and public communication.
- `jair-leadership-workshop.webp` — collaborative leadership, cross-functional dialogue and working-session context.
- `jair-panel-conversation.webp` — speaking, listening and external credibility.

Images are intentionally sparse. Each placement must reinforce a hiring signal rather than decorate the page. The `Media Quality` workflow validates that every displayed source is readable and above the site's high-resolution pixel threshold.
