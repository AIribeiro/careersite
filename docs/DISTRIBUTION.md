## Operating rule

Permanent surfaces use the attributed main site. Hiring interactions use the closest relevant contextual page.

Treat the site as supporting evidence, not a destination to advertise. Prefer wording such as `leadership cases beyond the CV`, `relevant perspective`, `the examples we discussed`, or `captured here if useful` instead of `visit my website`.

The production analytics taxonomy compares `linkedin`, `email`, `cv`, `outreach`, and `application`, with role attribution when supplied. The dashboard should be used to assess whether each source subsequently reaches Impact, opens a lens, or downloads the CV before changing distribution strategy.
